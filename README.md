# Retail Sales Dashboard | Power BI

## Overview
Interactive Power BI dashboard analyzing retail sales performance from 2015–2018.

## Features
- KPI Tracking (Revenue, Orders, Customers)
- Monthly Sales Trend Analysis
- Regional Sales Insights
- Category & Sub-Category Performance
- Ship Mode Analysis
- Dynamic Filters & Slicers

## Tools Used
- Power BI
- DAX
- Power Query
- Data Modeling

## Dashboard Preview
![Dashboard Screenshot](dashboard.png)

## Key Insights
- Technology category generated highest revenue
- Consumer segment contributed majority sales
- Standard Class had highest shipment count
